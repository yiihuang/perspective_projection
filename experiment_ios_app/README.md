# Perspective Projection Visualizer (iOS Experiment)

A high-performance interactive tool for visualizing 3D perspective projections, specifically focusing on linear and hemispherical (Postel) models. Built as a modern React web application and optimized for iOS deployment via Capacitor.

## 🌟 Key Features

### 3D Visualizer
- **Interactive Cube**: Rotate the cube using precise Euler angles (ZX'Z'') or local swipe gestures.
- **Dynamic Projections**: Real-time rendering of projection rays and intersection points on both planar and hemispherical image planes.
- **Modern UI**: Sleek, glassmorphic control panels tailored for mobile and tablet interaction.

### 2D Projection Views
- **Linear Projection**: Standard planar projection with a circular boundary.
- **Hemispherical Projection (Postel)**: Advanced azimuthal equidistant projection.
  - **Vanishing Point Continuity**: Correctly handles both "Inside" and "Outside" vanishing points to form continuous "Eye Lines".
  - **Advanced Arc Rendering**: Edges are rendered as geometric arcs passing through projected midpoints for perfect accuracy.
  - **Dynamic Segmentation**: Adaptive arc resolution based on curvature and radius for optimal performance/smoothness.

## 🛠 Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **3D Engine**: Three.js with `@react-three/fiber` and `@react-three/drei`
- **State Management**: Zustand (with optimized selectors for performance)
- **Styling**: Tailwind CSS + Framer Motion
- **Mobile Packaging**: Capacitor 6 (iOS target)

## 🚀 Getting Started

### Development
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

### iOS Setup
1. Build the web app:
   ```bash
   npm run build
   ```
2. Sync with the iOS project:
   ```bash
   npx cap sync ios
   ```
3. Open in Xcode:
   ```bash
   npx cap open ios
   ```

## 📂 Project Structure

- `src/components/canvas/`: Three.js components (Scene, 2D Views, Visualizers).
- `src/lib/math/`: Core projection mathematics and arc generation logic.
- `src/store.ts`: Global state management for viewpoint and rotation.
- `ios/`: Native Xcode project generated by Capacitor.

## 🧪 Mathematical Details

### Hemispherical Projection
The project implements a Postel projection where a point on the hemisphere surface is mapped to a 2D disk. 
Vertices behind the viewpoint are projected outside the boundary circle using the inversion formula:
$$d_{out} = \frac{R^2}{d_{in}}$$
while maintaining the original azimuth.

### Vanishing Points
Supports three axes of vanishing points, with "outside" points shifted by 180° to maintain topological continuity in the spherical 2D view.
